# inbox/

הקבצים הגולמיים נכנסים לכאן, כל מקור בתיקייה משלו:

```
inbox/
  cal/     דפי כאל
  max/     דפי מקס
  bank/    דפי עובר ושב
```

תומך ב-`.xlsx`, `.csv`, `.txt`. אפשר לזרוק כמה חודשים ביחד — הדדופ מטפל
בחפיפה ביניהם.

**התוכן של התיקיות האלה חסום ב-`.gitignore`.** דפי אשראי לא נכנסים ל-git.

## מקור חדש

צור תיקייה בשם המקור, שים בה קובץ, והרץ:

```bash
python3 scripts/detect.py inbox/<מקור>/<קובץ>
```

הסקריפט ידפיס בלוק להדבקה ב-`config/parsers.yaml`. אחרי שאימתת את כיוון הסימן
מול שורה שאתה בטוח לגביה, סמן `verified: true` והרץ `python3 scripts/run_all.py`.
