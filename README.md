# מעקב פיננסי אוטומטי — Claude Code

מערכת שמאחדת תנועות מבנק אוצר החייל, One Zero, ושני כרטיסי כאל, ומייצרת דו"ח ודשבורד חודשי.
**אין חיבור ישיר לשום בנק/אשראי** — המערכת עובדת רק על קבצים שאתה מייצא בעצמך. זו כוונת עיצוב, לא מגבלה זמנית.

## התקנה חד-פעמית

```bash
cd finance-tracker
pip install -r requirements.txt
```

ואז פתח את התיקייה עם Claude Code (`claude` מתוך התיקייה).

## השגרה החודשית שלך (כ-3 דקות)

1. **אוצר החייל**: אזור אישי ← תנועות חשבון ← ייצוא לאקסל/CSV → שמור לתוך `inbox/otzar-hahayal/`
2. **One Zero**: אפליקציה ← תנועות ← ייצוא לאקסל → שמור לתוך `inbox/onezero/`
3. **כאל**: אתר/אפליקציה ← דוח עסקאות לכל אחד משני הכרטיסים ← ייצוא → שמור את שני הקבצים לתוך `inbox/cal/` (שם הקובץ לא משנה)
4. פתח את Claude Code בתיקייה ותכתוב: **"עבד את החודש"**

זהו. Claude Code יזהה את הקבצים, ינרמל, יסווג, יעדכן את היומן המרכזי, ויפיק דשבורד חדש ב-`reports/<חודש>/dashboard.html`.

בפעם הראשונה שכל מקור מעובד, ייתכן שClaude Code ישאל אותך שאלה או שתיים כדי לזהות נכון את מבנה הקובץ (אחרי זה זה קורה אוטומטית, בלי שאלות).

## מבנה התיקייה

```
finance-tracker/
├── CLAUDE.md              ← ההוראות ש-Claude Code פועל לפיהן (אל תמחק)
├── inbox/                 ← לשם אתה מטמיע קבצים מיוצאים כל חודש
│   ├── otzar-hahayal/
│   ├── onezero/
│   └── cal/
├── data/transactions.csv  ← היומן המרכזי המאוחד (נבנה אוטומטית)
├── config/
│   ├── categories.yaml    ← חוקי סיווג — ניתן לערוך ידנית בכל עת
│   └── parsers.yaml       ← מיפוי עמודות פר-מקור — נבנה אוטומטית בפעם הראשונה
├── reports/<חודש>/        ← דשבורד + סיכום, נוצר מחדש כל הרצה
└── scripts/                ← קוד הניתוח (ingest.py, build_dashboard.py)
```

## מה נוסף מעבר לדשבורד הבסיסי

- **Git אוטומטי** — כל הרצה חודשית מסתיימת ב-commit, כך שיש לך היסטוריה מלאה של היומן הפיננסי. (בפעם הראשונה בלבד, אם Claude Code נתקל בשגיאת "Author identity unknown", תריץ פעם אחת: `git config user.email "you@example.com" && git config user.name "Name"`.)
- **דוח שנתי** — `reports/annual/<שנה>/annual-report.html`, נבנה מחדש אוטומטית בכל עדכון חודשי. מגמה חודשית + פילוח קטגוריות שנתי + השוואה לשנה קודמת.
- **זיהוי חריגות** — בכל דוח חודשי, השוואה אוטומטית של כל קטגוריה מול הממוצע ההיסטורי שלה (עד 6 חודשים אחורה), עם דגל לחריגה מעל 30%.
- **שני כרטיסי כאל בנפרד** — הדשבורד מציג אותם כחשבונות נפרדים (`cal-XXXX`/`cal-YYYY`), לא מאוחדים.
- **אופטימיזציית הטבות/נקודות** — בפעם הראשונה, Claude Code ישאל אותך פעם אחת מה ההטבות של כל כרטיס (`config/card_benefits.yaml`). מכאן והלאה, כל דוח חודשי כולל הצעות לקטגוריות ששילמת דרך כרטיס בלי הטבה, כשכרטיס אחר שלך כן מציע הטבה שם. **זו לא המלצה פיננסית מדויקת** (סוגי הטבות שונים - נקודות מול קאשבק - לא תמיד ניתנים להשוואה ישירה מספרית), אלא כיוון לבדיקה ידנית.

## שיפור עתידי אפשרי
אם אוצר החייל/כאל שולחים דו"ח חודשי כקובץ מצורף במייל, אפשר לחבר את Claude Code ל-Gmail (MCP) כדי שישלוף את הקבצים בעצמו — ואז השגרה החודשית שלך תרד ל-0 דקות. Claude Code יבדוק את זה לבד בהגדרה הראשונית אם יש לו גישה לכלי Gmail, אבל לא יפעיל את זה בלי אישור מפורש שלך.
